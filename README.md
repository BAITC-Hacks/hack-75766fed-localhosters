# Localhosters — HackAlem AI

Кейс: **Agentic AI для прогнозирования почасовой выработки ВЭС** на горизонте 24–48 часов.

Система должна сама проходить полный цикл: получить прогноз погоды из открытых источников → подготовить данные → запустить модель → выдать почасовой прогноз → проанализировать результат → пересчитать при обновлении входных данных. Проверка — бэктест за февраль 2026 с использованием **архивных** прогнозов погоды, доступных на момент каждого прогноза.

## Статус

🔬 **Ресёрч.** Изучаем источники архивных прогнозов, данные SCADA и архитектуру агента. План и задачи — в [`docs/research/`](docs/research/README.md).

SCADA интерпретируется как фиксированный UTC+6 на всём периоде: помесячный пик плавает 5.2–6.7 ч, вывод по pooled-окнам. Временные метки локализуются через `Etc/GMT-6`, а не `Asia/Almaty`; воспроизводимое доказательство находится в `scripts/tz_check.py` и `docs/figures/tz_xcorr.png`.

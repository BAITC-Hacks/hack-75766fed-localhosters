# Бэктест v1 через агента: test, dev и репетиция Feb 2025 (LOC-30)

Каждый выпуск проходит полный цикл агента (`run_issue`: Clock → архивный ран Single Runs → проверка
данных → `predict()` контракта LOC-12 → решение → trace). Модель сабмита — LightGBM v1 (бленд с v0),
на окнах с фактами — holdout-free бустер (`models/lightgbm_v1_holdout.txt`), так что dev и feb2025 —
вне выборки обучения.

```bash
make backtest-v1        # test: 29 dayahead + 29 reissue -> submission/forecast_test_*_v1.csv
make backtest-dev       # dev (январь 2026): v1 и v0 -> reports/backtest_{v1,v0}_dev{,_modes}.csv
make backtest-feb2025   # Feb 2025 (тот же сезон годом раньше): -> reports/backtest_{v1,v0}_feb2025{,_modes}.csv
```

Окна (целевые дни по SCADA; выпуск — 18:00 UTC накануне):

| Окно | Выпуски | Ран на выпуск | Reissue | Факты |
|---|---|---|---|---|
| `test` | 31.01–28.02.2026 (29) | 06Z того же дня; 12Z в 20:00 UTC | 29 | нет |
| `dev` | 31.12.2025–30.01.2026 (31) | 06Z | нет (в кеше только 06Z) | есть |
| `feb2025` | 31.01–28.02.2025 (29) | 06Z | нет (в кеше только 06Z) | есть |

`feb2025` совпадает с holdout `feb2025` в `windagent/model/v1.py`; целевые часы доходят до 1–2 марта 2025.

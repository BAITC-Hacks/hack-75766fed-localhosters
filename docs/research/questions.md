## Что мы уже знаем без ответа

- Архивные прогнозы на 31.01–28.02.2026 доступны бесплатно: Open-Meteo Single Runs (все 116 запусков ECMWF IFS 9 км, 0 пропусков) и Previous Runs (ecmwf_ifs, ifs025, aifs, icon_global, gfs_global).
- Historical Forecast API и Archive API для теста **не подходят**: это сшивка первых 0–5 часов каждого запуска, почти анализ. Используем только для обучения.
- Таймзона SCADA — фиксированный UTC+6, доказано кросс-корреляцией с ERA5 (лаг 6.0 ч до 01.03.2024 и 5.8 ч после) и отсутствием разрыва в 10-минутных строках в момент перехода страны на UTC+5.

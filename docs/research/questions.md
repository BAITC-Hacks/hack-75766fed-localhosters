# Открытые вопросы по условию — закрыты решениями команды

Задача в Linear: LOC-28. Организаторам вопросы не отправляли: 23.09.2026 команда закрыла их сама, опираясь на текст условия и на данные. Каждое решение вынесено в параметр, поэтому если организаторы потребуют иначе, пересчёт делается одной командой, без переписывания кода. Сводка «если иначе → что меняем» — в [assumptions.md](../assumptions.md).

| # | Вопрос | Решение команды | Почему | Параметр |

| 1 | Метрика: MAE или RMSE, в каких единицах, по турбинам или по ВЭС | Отчитываемся **MAE и RMSE** по нормализованной мощности (0..1, доля от 2.5 МВт) **по каждой турбине**, отдельно для первых и вторых суток горизонта. RMSE считаем рядом, чтобы результат читался при любой метрике | `POINT_ESTIMATE=median` |
| 2 | Таймзона меток результата | Основная метка — **часы SCADA (UTC+6)**, как в выданном датасете; рядом колонка UTC | Скрытые факты февраля почти наверняка в той же шкале, что и выданные CSV. Фиксированный UTC+6 доказан на данных (см. [findings](findings.md), [tz_xcorr.png](../figures/tz_xcorr.png)) | `SCADA_TZ_OFFSET_HOURS=6` |

Пересчёт в 20:00 UTC на ране 12Z показывает работу агента, но в сабмит идёт dayahead-выпуск | Буквальное прочтение условия: в дату выпуска прогноз строится на следующие 24–48 ч, только по данным, доступным на тот момент. Метрики даём в двух режимах: по всем часам с фактом и только по «объяснимым погодой» (без флагов простоя, обледенения, ограничения) | Прогноз простоя по погоде невозможен; честнее показать обе цифры, чем подгонять | флаги в `data/processed/scada_hourly.parquet` |

Все ответы закэшированы в репозитории с хешами | Условие оставляет выбор источника команде. Сырые GRIB ECMWF с AWS — путь развития (LOC-19) | — |

## На чём держатся решения

- Архивные прогнозы на 31.01–28.02.2026 доступны без ключа: Open-Meteo Single Runs (все 116 запусков ECMWF IFS 9 км) и Previous Runs (`ecmwf_ifs`, `ecmwf_ifs025`, `ecmwf_aifs025_single`, `icon_global`, `gfs_global`).
- Historical Forecast и Archive API для февраля **не используются**: это сшивка коротких заблаговременностей, почти анализ, а не прогноз, доступный на момент выпуска. Только для обучения и оценки; `best_match` запрещён.
- Доступность рана считается по циклу: 00Z и 12Z через 8 ч, 06Z и 18Z через 7 ч после запуска (публикация ECMWF open data 07:34 / 12:27 / 19:34 / 00:27 UTC). Проверяется тестом на каждую строку сабмита.
- Таймзона SCADA — фиксированный UTC+6: pooled кросс-корреляция с IFS 9 км и ERA5 до и после 01.03.2024, суточный максимум температуры в 15:00–15:30, нет разрыва строк в момент перехода страны на UTC+5.

## Что мы уже знаем без ответа

- Архивные прогнозы на 31.01–28.02.2026 доступны без ключа (free tier Open-Meteo, non-commercial): Single Runs (все 116 запусков ECMWF IFS 9 км, 0 null по 6 переменным) и Previous Runs (`ecmwf_ifs`, `ecmwf_ifs025`, `ecmwf_aifs025_single`, `icon_global`, `gfs_global`).
- Historical Forecast API и Archive API для теста **не подходят**: без `models` оба отдают один и тот же stitched IFS 9 км из коротких лидов (с 2025-10-01 — lead 0–5 ч четырёх ранов в сутки, почти анализ; ~11.2024–09.2025 — только 00Z/12Z lead 1–12 ч; ранее provenance неизвестен), ERA5 — только с `models=era5`. Используем только для обучения и оценки; `best_match` запрещён.
- Таймзона SCADA — фиксированный UTC+6, доказано pooled кросс-корреляцией с IFS 9 км (пик 5.83–6.00 ч) и ERA5 (6.00–6.17 ч) до и после 01.03.2024, суточным максимумом температуры в 15:00–15:30 и отсутствием разрыва в 10-минутных строках в момент перехода страны на UTC+5; помесячный пик плавает 5.2–6.7 ч, вывод — по pooled-окнам.

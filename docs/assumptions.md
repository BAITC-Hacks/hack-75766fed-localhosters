# Допущения до ответа организаторов (LOC-21/28)

Текст вопросов готов в [research/questions.md](research/questions.md). Отправка и ответы пока не подтверждены в Linear. Эти значения — рабочие настройки, не официальная спецификация организаторов.

| Неизвестное | Дефолт и причина | Если организаторы ответят иначе | Параметр |
|---|---|---|---|
| Метрика | MAE нормализованной мощности отдельно по турбине; для MAE точка близка к медиане | Считать RMSE и mean, изменить критерий выбора модели; не переименовывать старый результат | `POINT_ESTIMATE` |
| Таймзона меток | UTC+6 фиксировано в SCADA, UTC отдельно; подтверждено кросс-корреляцией | Меняем сериализацию и джойн с фактами, повторяем replay | `SCADA_TZ_OFFSET_HOURS` |
| Выпуск и горизонт | 18:00 UTC, 48 последовательных часовых интервалов с этого часа; часы размечены началом | Меняем Clock и окно, повторяем все CSV | `ISSUE_HOUR_UTC`, `HORIZON_HOURS` |
| Повторный выпуск | При новом опубликованном ране, только будущие интервалы | Отключаем повторные версии, оставляем базовый выпуск | `REISSUE_ON_NEW_RUN` |
| Формат CSV | По строке на issue × target × турбину и отдельный плоский CSV на target × турбину | Меняем только экспорт, сохраняем внутреннюю схему | `SUBMISSION_FORMAT` (план, ещё не настроен) |
| Пропуски SCADA | Прогноз для всех часов, оценка только на известных актуалах; отчёт даёт покрытие | Подстроим маску метрик и экспорт, не обучаемся на скрытом феврале | `EVALUATION_MASK` (план) |
| Источник погоды | Open-Meteo Single Runs `ecmwf_ifs` с сохранённым as-issued run и кешем | При запрете переключаем адаптер на raw GRIB и пересчитываем replay | `NWP_SOURCE` (план) |

В v0 `p50` — точка MOS + эмпирическая кривая. `p10/p90` получены из квантилей обучающих остатков; покрытие на независимом окне ещё надо проверить в LOC-11. Февральские SCADA-факты скрыты, поэтому MAE test-окна неизвестен.
